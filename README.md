# blog-code

The code and raw measurements behind posts on
[blog.kamelhar.net](https://blog.kamelhar.net).

An article that quotes a number should hand you the thing that produced it.
One directory per post; each has a README saying which figure in the article
came from which run, and what the run does not show.

| Directory | Post |
| --- | --- |
| [`dgx-spark-local-inference/`](dgx-spark-local-inference/) | [Running the Model Is the Easy Part](https://blog.kamelhar.net/serving-an-llm-on-an-nvidia-dgx-spark/) |
| [`this-blog/`](this-blog/) | the site itself — Ghost, the theme, and the machinery that keeps the writing in git |

These are working files, not a product. They ran on one machine, against one
model, and they are published so the claims can be checked rather than so the
scripts can be depended on.
